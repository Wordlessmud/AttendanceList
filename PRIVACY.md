# Privacy Policy for Attendance List

Last updated: 2 August 2026

Attendance List is an offline-first application for recording attendance and other configurable class or group events. This policy explains how the application handles information.

## Information handled by the application

Users may enter information such as:

- organization and class names;
- names or identifiers of people in a class or group;
- attendance and other event statuses;
- dates, notes, schedule settings, calendar exceptions and reminder text;
- report and export configuration.

This information may be personal information depending on how the application is used.

## Local storage

Attendance List stores working data in a local SQLite database in the application's private data directory on the user's device. The application is designed to work without an online account or cloud service.

The application does not intentionally transmit the working database, attendance records, names, notes or reports to the developer or to an external service.

## Exports and sharing

Users can create spreadsheet exports and may choose to save, copy or share those files using features provided by the operating system. Once a user exports or shares a file, the file is handled by the location, application, service or recipient selected by that user. Users are responsible for choosing an appropriate destination and for protecting exported information.

## Notifications

Reminder schedules and notification text are processed locally by the device operating system. Reminder content normally contains class and event names and does not contain individual person names unless a user manually enters such information into custom reminder text.

## Diagnostic information

If reminder scheduling fails, the application may create a local diagnostic file named `notification-errors.log` in the application data directory. This file is not automatically transmitted to the developer. A user may choose to share it when requesting support. Users should review diagnostic files before sharing them and remove any information they consider sensitive.

## Analytics, advertising and tracking

The current application does not include advertising, behavioral tracking, third-party analytics or developer-operated telemetry. It does not sell personal information.

## Data retention and deletion

Data remains on the device until it is edited or deleted by the user, removed by an application operation, or removed when the application and its local data are uninstalled or cleared. Users should create and securely retain any exports they need before uninstalling the application.

A full user-facing backup and restore workflow is not currently provided.

## Children and organizational use

Attendance List may be used by schools, childcare services, clubs, workplaces or other organizations. The person or organization using the application is responsible for having an appropriate lawful basis and permission to enter, process, retain and export information, including information about children or other protected individuals.

## Security

Users should protect access to their Windows or Android device and should store exported files in an appropriate secure location. No application can guarantee absolute security.

## Changes to this policy

This policy may be updated when application behavior changes. Material changes will be documented in the project repository and release notes.

## Contact and support

Support requests and privacy questions can be opened through the Attendance List GitHub repository. Do not include real attendance records, personal information, database files or other sensitive material in a public issue.
