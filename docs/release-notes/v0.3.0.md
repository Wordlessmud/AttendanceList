# Attendance List v0.3.0

This is the first public source release of Attendance List, an offline-first .NET MAUI application for Windows and Android.

> **Release status:** source-first preview. A publicly trusted signed Windows MSIX is not attached yet. Do not install unsigned packages from third parties.

## Highlights

- Manage multiple organisations, classes and class memberships.
- Record attendance, meals and configurable custom events.
- Configure positive, negative, neutral and excused status meanings.
- Track event completion independently by class, date and event.
- Review history and distinguish missing dates from incomplete records.
- Generate configurable XLSX reports and summaries.
- Schedule local reminders by weekday and time.
- Use the interface in English or Simplified Chinese.
- Keep operational data locally in SQLite unless explicitly exported.

## Windows reminder reliability

This release includes important fixes for Windows reminders:

- Windows scheduling now requires genuine MSIX package identity.
- Concurrent schedule refreshes are serialised.
- Notification errors include exception type and HRESULT.
- Full notification exceptions are written to `notification-errors.log` in the app data directory.

Windows reminder testing must use an installed MSIX launched from the Start menu. Running a loose executable from the publish directory is unsupported.

## Downloads

GitHub provides source-code ZIP and tarball downloads for this tag.

A generally installable Windows binary will be added in a later release after the MSIX is signed through Microsoft Store, SignPath Foundation or another publicly trusted signing service.

## Build requirements

- Windows development machine
- .NET 10 SDK
- .NET MAUI workload

```powershell
dotnet restore
dotnet workload restore
dotnet test .\AttendanceList.Tests\AttendanceList.Tests.csproj
```

See `README.md`, `CONTRIBUTING.md`, and `docs/RELEASING.md` for build and release details.

## Known limitations

- No complete user-facing database backup and restore workflow yet.
- No roster import or bulk roster editing yet.
- Reminder deep links are not implemented.
- Accessibility, keyboard navigation and device UI automation need further work.
- Publicly trusted Windows and Android binaries are not included in this source-first release.
